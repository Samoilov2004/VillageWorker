ИДЕИ ДЛЯ УЛУЧШЕНИЯ DEMO

1. ФИЛЬТРЫ НЕ РАБОТАЮТ
   Чекбоксы (образование, опыт, оборудование) и слайдер радиуса рендерятся,
   но не отправляются в API. Нужно передавать их параметрами в /api/jobs.

2. КАРТА ЗАХАРДКОЖЕНА НА МОСКВУ
   setView([55.7558, 37.6173]) — Москва. Для сельской платформы центр карты
   должен либо определяться по геолокации, либо браться из выбранного региона.

3. КНОПКА "ОТКЛИКНУТЬСЯ" ПУСТАЯ
   В модальном окне кнопка ничего не делает. Можно сделать хотя бы форму
   с именем/телефоном и сохранять отклик в SQLite (таблица applications).

4. МЁРТВЫЕ ССЫЛКИ В НАВИГАЦИИ
   "Отклики" и "Поддержка" ведут на #. Можно реализовать страницу "Мои отклики"
   (список вакансий, на которые кликнули "Откликнуться") и статичную "Поддержка".

5. НЕТ ПАГИНАЦИИ / ПОДГРУЗКИ
   Все вакансии грузятся разом. Добавить limit/offset в /api/jobs и кнопку
   "Загрузить ещё" на фронте — уменьшит нагрузку и улучшит UX.

6. НЕТ СОРТИРОВКИ
   Нет выбора порядка: по зарплате, по дате добавления. Добавить sort= параметр
   в API и дропдаун на странице поиска.

7. ПРОФИЛЬ СТАТИЧНЫЙ
   profile.html не связан с бэкендом — поля не сохраняются. Добавить POST /api/profile
   и LocalStorage для хранения данных в рамках демо без настоящей авторизации.

8. СЧЁТЧИК РЕЗУЛЬТАТОВ ОТСУТСТВУЕТ
   После поиска не видно сколько вакансий найдено. Вывести "Найдено N вакансий"
   над списком карточек.

9. ЗАПУСК 3 ТЕРМИНАЛОВ ВРУЧНУЮ
   Можно добавить start.sh / start.bat — один скрипт, который поднимает backend,
   ml_service и frontend одновременно (через & или start).

10. ПРОЦЕНТ СХОДСТВА В ПОХОЖИХ ВАКАНСИЯХ
    "Сходство: 87%" — внутренняя ML-метрика, пользователю не говорит ничего.
    Убрать или заменить на человекочитаемое: "Очень похожая", "Похожая".
